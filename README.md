# Financial Statistics Dashboard (Excel)
## 🧭 Dashboard Overview
The Financial Statistics Dashboard System is a modern, interactive Excel solution designed to help analysts and managers turn raw financial data into clear, actionable insights.
With built-in navigation, slicers, KPI cards, and visually polished components, users can explore income trends, geographic contributions, sales funnel performance, and project flow analysis — all in minutes.

---

## 🔑 Key Features & Components
### Interactive Reporting Areas

**Income Sources Hub**:
Radial bubble visuals highlighting income mix, plus a progress gauge to track target achievement.

**Geographical Analysis**:
Interactive map with country-level callouts and a contribution table for quick comparison.

**Sales Process Flow**:
End-to-end funnel from visitors → orders → paid customers → fulfillment, including refunds.

**Project Status View**:
Clean, Sankey-style flow showing project movement across various stages in the portfolio.
